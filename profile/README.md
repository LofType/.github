# Löf

A dependent type theory and type system on the Wolfram Language.

Löf serves two purposes:

- **Proofs:** writing and checking proofs in a rigorous type-theoretic setting.
- **Typed computation:** typing mathematical and physical code written in the Wolfram Language.

> **Status:** early development. Interfaces and repositories will change.
